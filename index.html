PROJECT GEÏNSTALLEERD

Je Next.js website staat klaar!

Je ziet deze pagina omdat je de Go Live knop gebruikt. Voor een Next.js project (zoals gevraagd in je opdracht) moet je een ander commando gebruiken om de site echt te zien:

Stap 1: Open de Terminal in VS Code.
(Ga naar bovenin het menu: Terminal > New Terminal)
Stap 2: Typ het volgende commando en druk op Enter:
npm run dev
Stap 3: Klik op de link die in de terminal verschijnt:
http://localhost:3000

Je vindt je 3 artikels (AI-Slop, Vibecoding en Dario Amodei) terug in het menu zodra de site draait. Succes!
